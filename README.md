# Asociación de Juventud Intelectual — versión GitHub Pages

Sitio web estático preparado para publicarse gratuitamente con GitHub Pages.

## Importante
GitHub Pages publica HTML, CSS y JavaScript estáticos. Por eso esta versión no utiliza PHP, SQLite ni un panel administrativo. Los formularios están configurados para preparar un correo dirigido a `asociacionjuventudintelectual@gmail.com` mediante el programa de correo del visitante.

## Publicación gratuita
1. Crea o inicia sesión en GitHub.
2. Crea un repositorio **público**. Si quieres la dirección más sencilla, usa el nombre `TUUSUARIO.github.io`.
3. Sube **todo el contenido de esta carpeta**, incluyendo `index.html` y la carpeta `assets`.
4. En el repositorio entra a **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**.
6. Elige la rama `main` y la carpeta `/ (root)` y guarda.
7. GitHub te mostrará la dirección publicada. Los cambios pueden tardar unos minutos en aparecer.

## Archivos principales
- `index.html`: sitio completo.
- `assets/style.css`: diseño y responsive.
- `assets/logo.png`: logo.
- `assets/invitacion-asociacion.png`: material institucional.

## Para agregar noticias o fotos
Puedes editar `index.html` directamente desde GitHub. Para fotos nuevas, súbelas a `assets/` y luego agrega el bloque correspondiente dentro de la sección `Galería`.

## Próximo paso opcional
Si quieres conservar un panel para que ustedes publiquen noticias, fotos y reciban formularios sin editar código, habría que usar un servicio/backend compatible con GitHub Pages. Esta carpeta está pensada como la versión gratuita y sencilla para dejar la web pública primero.
